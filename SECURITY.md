# Security

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/EricVogt93/artcraft-launcher/security/advisories/new). Include the version, affected platform, reproduction steps and impact. Do not include credentials or personal files in reports.

App packages are accepted only from the corresponding `storytold` GitHub releases and are checked against their published SHA-256 metadata. This checks download integrity; it is not an independent publisher signature. Launcher self-updates use a separately configured Ed25519 key and currently support local signed feeds.

Security fixes target the latest `main` version. No response-time commitment is currently offered.
